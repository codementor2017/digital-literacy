Course Description

This course introduces students to the fundamental principles of designing algorithms and writing simple programs to solve real-world mathematical and scientific problems. Students will learn to apply abstract concepts in computational thinking to break down complex problems and develop efficient solutions. Through hands-on exercises, they will design and implement basic programs that address practical challenges.

Additionally, the course covers essential data handling skills, including collecting primary data, processing and evaluating it using various software tools, and presenting findings effectively. Students will also explore responsible and safe use of information technology, adhering to ethical guidelines when accessing media and online resources.

Indicators: Sci 4.2 Technology (Computational Science)

Algorithm Design
  • Design an algorithm that uses abstract concepts to solve a problem or describe a function encountered in real life.
Programming
  • Design and write simple programs to solve mathematical or scientific problems.
Data Handling
  • Collect primary data, process, evaluate, present data and information according to the objectives using various software or internet services.
Digital Ethics & Safety
  • Use information technology safely, use media and information sources according to the terms and conditions.
